# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Security Engineers, DevSecOps practitioners, Platform Owners, and Full-Stack Developers building and deploying modern AI-accelerated web applications and APIs.

## Product Purpose

Zerivex is an autonomous continuous application security platform that provides deterministic vulnerability scanning, cryptographic target ownership verification (DNS TXT, HTML Meta, Well-Known files), SSRF egress protection, and automated fix verification for production endpoints.

## Positioning

Unlike generic or black-box vulnerability scanners that produce high rates of false positives and spam alerts, Zerivex enforces cryptographic ownership verification before executing intrusive tests, delivers multi-framework remediation code snippets (Next.js, Express, Nginx), and enables instant 1-click live fix re-verification.

## Operating Context

Cloud and on-premise web environments, CI/CD deployment pipelines, DNS management consoles (Cloudflare, Route 53, Vercel), terminal command lines, and executive compliance audits.

## Capabilities and Constraints

- **Autonomous continuous defense**: Real-time passive checks and verified active scanning.
- **Cryptographic target verification**: Scoped to exact hosts or apex domains.
- **Deterministic findings triage**: Standardized severity levels (CRITICAL, HIGH, MEDIUM, LOW, INFO) mapped to OWASP Top 10 and CWE.
- **SARIF 2.1.0 and RFC 4180 CSV exportability**: Immutable audit trail in the Compliance Audit Vault.
- **Modern UI Architecture**: Next.js 16 App Router, React 18, Vanilla CSS custom properties (`[data-theme="dark"]` and `[data-theme="light"]`), GSAP motion, and React Bits micro-typography.

## Brand Commitments

- **Tone & Atmosphere**: "Quietly expensive security infrastructure" — sophisticated, restrained, technical, precise, zero AI-slop, zero excessive glow/blur.
- **Palette**: Deep Obsidian (#07090e) Dark theme, Clean Slate (#f8fafc) Light theme, Cyber Blue (#3b82f6), Emerald Mint (#10b981), Warning Amber (#f59e0b), and Critical Crimson (#ef4444).
- **Typography**: Plus Jakarta Sans (body, titles, navigation) and JetBrains Mono (status badges, hosts, ciphers, code).

## Product Principles

1. **Deterministic Over Heuristic**: Every finding must be backed by verifiable evidence.
2. **Quietly Expensive Craft**: Restrained, high-density, professional visual hierarchy without decorative gimmicks.
3. **Cryptographic Proof of Authority**: No intrusive actions without verified domain ownership.
4. **Instant Actionability**: Never report a problem without concrete, copy-pasteable remediation code and automated verification.
